## 📊 PROJECT OVERVIEW

QRPiPay is a revolutionary payment terminal for Pi Network that allows merchants to:
- Generate QR codes for Pi payments in 10 seconds
- Accept payments from Pi Browser instantly
- Track payments with real-time analytics
- Export transaction data
- Manage multiple payment streams

**Built with:** React 18, Node.js 20, PostgreSQL, TypeScript, Docker, Render
