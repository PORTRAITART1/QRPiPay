## 📋 TEST SCENARIOS

### Scenario 1: User Onboarding
**Goal:** Test user's first experience

**Steps:**
1. Open app for first time
2. See login page
3. Understand what it does
4. Feel confident to proceed

**Success Criteria:**
- [ ] User understands purpose
- [ ] Clear instructions
- [ ] No confusion
- [ ] User wants to continue

**Questions:**
- How clear was the purpose?
- Did you understand what to do?
- Any confusing parts?
- Would you continue?

---

### Scenario 2: QR Code Generation
**Goal:** Test core feature

**Steps:**
1. Login successfully
2. Navigate to QR Generator
3. Enter amount (e.g., 100 Pi)
4. Enter description
5. Generate QR code
6. See result

**Success Criteria:**
- [ ] Process is intuitive
- [ ] Form validation works
- [ ] QR code generates
- [ ] Result is clear

**Questions:**
- How easy was it?
- Did you understand each step?
- Any issues?
- How could it be better?

---

### Scenario 3: Payment History
**Goal:** Test history and management

**Steps:**
1. Generate few payments
2. Navigate to history
3. View list
4. Try filters
5. Try sorting
6. Try export

**Success Criteria:**
- [ ] History displays correctly
- [ ] Filters work
- [ ] Sorting works
- [ ] Export works

**Questions:**
- Is the layout clear?
- Are filters helpful?
- What information is missing?
- How useful is this feature?

---

### Scenario 4: Design & Aesthetics
**Goal:** Test visual design

**Steps:**
1. Look at entire app
2. Navigate through pages
3. Try dark mode
4. View on mobile
5. Assess overall feel

**Success Criteria:**
- [ ] Design looks professional
- [ ] Colors are appealing
- [ ] Layout is organized
- [ ] Responsive works

**Questions:**
- How do you rate the design?
- What's your favorite part?
- What doesn't look good?
- Light or dark mode preference?

---

### Scenario 5: Accessibility
**Goal:** Test for accessibility

**Steps:**
1. Navigate with keyboard only
2. Use screen reader (if available)
3. Check text readability
4. Check color contrast
5. Test on mobile

**Success Criteria:**
- [ ] Keyboard navigation works
- [ ] Focus visible
- [ ] Text readable
- [ ] Mobile works

**Questions:**
- Can you navigate with keyboard?
- Is text readable?
- Any accessibility issues?
- Suggestions for improvement?

## 🎤 INTERVIEW SCRIPT

### Introduction
```
"Thank you for testing QRPiPay! 

This is a Pi Network payment terminal app. 
We're testing it with real users to get feedback.

There are no wrong answers - we want your honest opinion.

This should take about 15-20 minutes.

Ready? Let's start!"
```

### Opening Question
```
"Before we start, have you used any payment apps before?
Can you describe your experience?"
```

### During Testing
```
"Go ahead and try [feature]"
"What are you thinking right now?"
"Is this what you expected?"
"Would you do anything differently?"
```

### After Task
```
"How would you rate that? 1-5?"
"What was confusing (if anything)?"
"What worked well?"
"Any suggestions?"
```

### Closing Questions
```
"Overall, how would you rate the app?"
"Would you use this app?"
"Would you recommend to friends?"
"Any final thoughts?"
```
