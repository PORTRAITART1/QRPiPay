# QRPiPay - Accepte Pi en 10 secondes

Application de paiement Pi Network avec QR codes, design premium et sécurité quantique.

## 🚀 Stack Technique

- **Frontend**: React 18 + TypeScript + Vite + TailwindCSS
- **Backend**: Node.js + Express + PostgreSQL
- **Crypto**: Post-Quantum Cryptography (CRYSTALS-Kyber)
- **Pi Network**: Pi SDK + PiRC-2 Smart Contracts

## 📁 Structure

```
QRPiPay/
├── frontend/          # React app
├── backend/           # API serveur
├── database/          # PostgreSQL schemas
├── contracts/         # Smart contracts Pi
├── docs/              # Documentation
└── .github/           # CI/CD
```

## ⚡ Quick Start

```bash
# Frontend
cd frontend
npm install
npm run dev

# Backend
cd backend
npm install
npm run dev

# Database
cd database
npm run migrate
```
