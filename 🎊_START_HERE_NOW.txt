🆘 QUICK TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

Frontend Blank Page?
├─ F12 → Console
├─ Look for red errors
├─ Check VITE_API_URL
└─ Clear cache & try incognito

Backend Build Fails?
├─ Backend → Logs
├─ Read error message
├─ Fix code
└─ Push to GitHub (auto redeploy)

Database Connection Error?
├─ Verify DATABASE_URL
├─ Check it's INTERNAL URL
├─ Verify user/password
└─ Copy URL again if needed

CORS Errors?
├─ Check FRONTEND_URL in backend
├─ Check VITE_API_URL in frontend
└─ Both should be Render URLs
