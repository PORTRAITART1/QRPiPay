# Privacy Policy - QRPiPay

**Last Updated**: December 12, 2025

## 1. Introduction

QRPiPay ("we", "us", "our", or "Company") operates the QRPiPay application (the "Service").

This page informs you of our policies regarding the collection, use, and disclosure of personal data when you use our Service and the choices you have associated with that data.

We use your data to provide and improve the Service. By using the Service, you agree to the collection and use of information in accordance with this policy.

## 2. Information Collection and Use

### 2.1 Types of Data Collected

#### Personal Data
- **Pi Network User Information**
  - Pi UID (unique identifier)
  - Pi Username
  - Email address (if provided)
  - Business name and category
  - KYC verification status

- **Payment Information**
  - Transaction amounts (in Pi)
  - Payment descriptions
  - Transaction timestamps
  - Payment status
  - Buyer information (username, Pi UID)
  - Blockchain transaction IDs (txid)

- **Usage Information**
  - Login history
  - QR code generation data
  - Payment history
  - Analytics data
  - Device information
  - IP address
  - Browser type and version

#### Non-Personal Data
- Aggregated analytics
- App performance metrics
- Feature usage statistics
- Error logs
- Security logs

### 2.2 Purpose of Collection

We collect personal data for the following purposes:

1. **Service Provision**
   - Enable payment transactions
   - Generate QR codes
   - Maintain transaction history
   - Provide user authentication

2. **Service Improvement**
   - Analyze usage patterns
   - Identify and fix bugs
   - Enhance features
   - Improve performance

3. **Security & Fraud Prevention**
   - Prevent fraudulent transactions
   - Detect unauthorized access
   - Monitor for security threats
   - Protect against malicious activity

4. **Compliance**
   - Comply with legal obligations
   - Respond to legal requests
   - Enforce Terms of Service
   - Protect legal rights

5. **Communication**
   - Send service updates
   - Notify of changes
   - Provide customer support
   - Send security alerts

## 3. Data Retention

- **User Account Data**: Retained during active account use
- **Payment Records**: Retained for 7 years (tax/legal requirement)
- **Temporary Data**: Deleted after 90 days
- **Logs**: Retained for 30 days
- **Analytics**: Aggregated data retained indefinitely

Users can request data deletion at any time (subject to legal requirements).

## 4. Data Protection

### 4.1 Security Measures

We implement appropriate technical and organizational measures to protect personal data:

- **Encryption**: HTTPS/TLS for data in transit
- **Database Security**: PostgreSQL with encryption at rest
- **Access Control**: Role-based access control (RBAC)
- **Authentication**: Strong password hashing (bcrypt)
- **Rate Limiting**: Protection against brute force attacks
- **Input Validation**: Zod validation on all inputs
- **Audit Logging**: All sensitive operations logged
- **Regular Updates**: Security patches and updates

### 4.2 Data Sharing

**We DO NOT share personal data with**:
- ❌ Third-party advertisers
- ❌ Data brokers
- ❌ Marketing companies
- ❌ Unauthorized parties

**We DO share data with**:
- ✅ Pi Network API (required for payment processing)
- ✅ Blockchain (transaction IDs, public records)
- ✅ Service providers (hosting, databases)
- ✅ Legal authorities (when required by law)
